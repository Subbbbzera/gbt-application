# Gold Bud Trans (Оренда та продаж спецтехніки)

Веб-додаток для компанії **Gold Bud Trans**, що надає послуги з оренди та продажу будівельної спецтехніки. Проєкт складається з клієнтської частини (Frontend) на React та серверної частини (Backend) на Express.js з базою даних MySQL.

---

## 🛠️ Технологічний стек

*   **Frontend**: React.js, TailwindCSS, React Router, React Icons, Context API
*   **Backend**: Node.js, Express.js, JWT (для авторизації), Multer (завантаження документів), Nodemailer (email-сповіщення)
*   **База даних**: MySQL

---

## 🚀 Як запустити проєкт локально

### Крок 1. Передумови
Переконайтеся, що на вашому комп'ютері встановлено:
*   [Node.js](https://nodejs.org/) (версія 16+)
*   [MySQL Server](https://dev.mysql.com/downloads/installer/) (або локальне середовище на кшталт XAMPP, Laragon, OpenServer)

---

### Крок 2. Налаштування бази даних
1.  Запустіть ваш локальний сервер **MySQL**.
2.  Створіть порожню базу даних з назвою `my_store`:
    ```sql
    CREATE DATABASE my_store;
    ```
3.  Імпортуйте структуру та початкові дані з файлу `database_schema.sql` у створену базу даних:
    *   **Через термінал/консоль**:
        ```bash
        mysql -u root -p my_store < database_schema.sql
        ```
    *   **Або** скопіюйте вміст файлу `database_schema.sql` та виконайте його в інтерфейсі (phpMyAdmin, DBeaver, MySQL Workbench тощо).

---

### Крок 3. Налаштування та запуск Бекенду (Server)
1.  Перейдіть у папку бекенду:
    ```bash
    cd backend
    ```
2.  Встановіть залежності:
    ```bash
    npm install
    ```
3.  Налаштуйте змінні оточення:
    *   Скопіюйте файл `.env.example` та перейменуйте його на `.env`:
        ```bash
        cp .env.example .env
        ```
    *   Відкрийте створений файл `.env` та вкажіть реквізити вашого підключення до MySQL (хост, користувач, пароль), а також налаштування пошти (Gmail) та Telegram бота для отримання сповіщень про замовлення.
4.  Запустіть сервер у режимі розробки:
    ```bash
    npm run dev
    ```
    *(Сервер запуститься за адресою `http://localhost:5000`)*

---

### Крок 4. Налаштування та запуск Фронтенду (Client)
1.  Відкрийте нову вкладку терміналу та перейдіть у папку фронтенду:
    ```bash
    cd frontend
    ```
2.  Встановіть залежності:
    ```bash
    npm install
    ```
3.  Запустіть клієнтську частину:
    ```bash
    npm start
    ```
    *(Сайт відкриється у вашому браузері за адресою `http://localhost:3000`)*
